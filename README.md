# Quan Ly Bai Giu Xe

Du an C quan ly bai giu xe. Xem ma nguon trong thu muc `src/`, header trong `include/`, tai lieu trong `docs/` va bo kiem thu trong `tests/`.

## Bien dich

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic -Iinclude src/*.c -o parking
```

Chay: `./parking` (Linux/macOS) hoac `parking.exe` (Windows).
